# Git Commands to Push to GitHub Repository
# Repository: https://github.com/KodaliSuchitraKamala/Team_Task_Manager

# Step 1: Initialize Git Repository
git init

# Step 2: Add Remote Repository
git remote add origin https://github.com/KodaliSuchitraKamala/Team_Task_Manager.git

# Step 3: Add All Files
git add .

# Step 4: Create Initial Commit
git commit -m "Initial commit: Team Task Manager full-stack application"

# Step 5: Push to GitHub
git push -u origin main

# If main branch doesn't exist, use:
# git push -u origin master

# Alternative if you encounter issues:
# git branch -M main
# git push -u origin main
